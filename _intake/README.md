# _intake (weekly drop zone)

Drop each week's raw mentorship material here. This is a staging inbox, not a kept record.
Once a file is distilled into the guide it moves to `processed/`.

## What to drop
- PDFs and slide exports — I read these directly.
- Screenshots / images of slides or calls — I read these directly.
- Pasted notes or transcripts — paste into a `.md` or `.txt` file.

## Video / call recordings
I cannot watch raw video or listen to audio. For a recording, do one of:
- paste a transcript, or
- bullet the key points you want captured.

## Naming
`YYYY-MM-DD-topic-shorthand.ext`
Examples: `2026-05-25-hooks-workshop.pdf`, `2026-06-01-targeting-notes.md`

The date just keeps the inbox in order. The finished guide is organized by topic, so I sort
each file into the right `guide/NN-*.md` when I process it.

## After processing
I move the raw file into `processed/` and log it in the status table in the project README.
